# TicTacToe
TicTacToe is common little game which I recreated in python with pygame and random.
Maybe you've to run some commands to be able to play this game:

```bash
sudo apt install python3
sudo apt install python3-pip
pip install pygame random
```

When you want an application, you have to use pyinstaller:

```bash
pip install pyinstaller
pyinstaller TicTacToe.py --onefile
```

To clone the repository, you have to make some use of git:

```bash
git clone https://github.com/FRAGE-zeichen/TicTacToe.git
```

I hope my instructions helped you!
